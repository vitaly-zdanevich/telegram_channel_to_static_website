Status update about my "media center" Youta (TUI audio player for Youtube and other sources). It was a productive few months about this project that I love. With {{ tag(t="llm") }} - the development is so fast. Its a new language for me - {{ tag(t="rust") }} (because of CPU/RAM), and I mostly do not read the code - but I validate the result as a user, and we (me and {{ tag(t="codex") }}) have {{ tag(t="tests") }}.  

Started as not a big project - just play Youtube, oh ok lets play this website also, and this, and local files - so good file manager was integrated. And now - it has many unusual powerful features, unique for an audio player. {{ tag(t="wikidata") }} integration / [AcoustID](https://acoustid.org/), domain information, even ":" command-mode as in Vim, and ability to add custom buttons (for example, if you want to call **FFmpeg** for a file with predefined set of parameters).  

And improvements, improvements of many details, performance, usability, simplicity. Media center of dream. My friend **Kiryl Tarasenka** added real GUI (based on web tech), great, thanks, just I am more into TUI.  

From Youta - you can also upload to {{ tag(t="commons") }}, {{ tag(t="internet_archive") }} (and play from it and {{ tag(t="librivox") }}), {{ tag(t="evernote") }} - I do not know any other "audio player" with such functions.  

And recently I added something crazy - youta can show a QR for a {{ tag(t="youtube") }} channel - so your phone can fetch all (or after some episode) audios to a {{ tag(t="podcast") }} app (for example {{ tag(t="antennapod") }}), through your {{ tag(t="lan") }}, can you imagine that.
